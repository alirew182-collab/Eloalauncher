# Отчёт о тестировании

Окружение: Linux-контейнер, JDK 21, Gradle 8.14.3, Android SDK 36. **Эмулятора и физического
устройства нет** (нет `/dev/kvm`). Сетевая политика контейнера блокирует серверы Mojang/Fabric/Forge.

## Что запускалось (и проходит)

Команда `./gradlew test` — 176 уникальных тестов; для Android-модулей они выполняются в вариантах
debug и release (всего 218 прогонов), 0 падений. `./gradlew :app:lintDebug` — 0 ошибок.

Ошибки, найденные тестами и исправленные (каждая закреплена тестом): переполнение int в AXML-парсере
(фаззинг), потеря `inheritsFrom` при многоуровневом наследовании профилей, NPE при `null` списке
системных функций, падение ограничения частоты кадров без дисплея у контекста.

## Что НЕ запускалось

* **Инструментальные тесты на устройстве/эмуляторе** — нет окружения. UI-тесты выполнены в Robolectric.
* **Реальная установка APK через PackageInstaller и запуск Minecraft Bedrock** — нужен Android-девайс.
* **Реальные запросы к Mojang/Fabric/Forge/Microsoft** — заблокированы сетью; логика проверена на MockWebServer.
* **Release-сборка (R8) на устройстве** — собрана и подписана, проверены подпись, манифест и сохранение
  сериализаторов, но работа минифицированного APK не проверялась запуском.
* **Производительность** (FPS, время запуска) — не измерялась; никаких обещаний прироста FPS нет.
* **Исполнение Java Edition** — отсутствует backend (см. ARCHITECTURE.md).
* Диалог с текстовым полем внутри полного приложения под Robolectric не достигает idle (окно диалога
  остаётся с pending layout); компонент проверен изолированно в теме приложения, а операции, которые
  он запускает, — интеграционными тестами. На устройстве требует ручной проверки.

## Рекомендуемая ручная проверка на устройстве
1. Импорт официальных APK Bedrock (base + split), установка, запуск, конфликт подписи.
2. «Open in Minecraft» для .mcpack и .mcworld.
3. Вход Microsoft с собственным Client ID; установка профиля Fabric с реальной загрузкой.
4. Диалоги ввода (новая папка, переименование), выбор файлов SAF, уведомление загрузки и отмена.
