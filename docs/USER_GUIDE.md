# Инструкция пользователя Eloa Launcher

## Первый запуск
1. Откройте **Настройки → Производительность**: лаунчер измерил устройство (SoC, CPU, GPU, RAM,
   Vulkan/OpenGL ES, температура) и предложил пресет. Пресет меняет только настройки лаунчера и
   значения по умолчанию для новых профилей; системные настройки не изменяются.
2. Выберите тему, акцентный цвет, при необходимости «Уменьшить анимации».
3. Навигация: меню ☰ слева (на планшетах — постоянная панель).

## Minecraft Bedrock Edition
* **Bedrock Edition → Import APK** — выберите один или несколько файлов `.apk`, `.apks`, `.xapk`
  (например, base + `split_config.arm64_v8a.apk`). Лаунчер только читает оригиналы и никогда их не удаляет.
* Перед добавлением проверяются: структура архива и CRC всех записей, подпись (v1–v4) и сертификат,
  package name, version name/code, ABI, minSdk, совместимость с устройством, дубликаты.
* Карточка версии: **Launch**, **Install** (через системный установщик Android — подтверждаете вы),
  **Verify**, **Select**, **Rename**, **Notes**, **Remove** (с выбором — удалять ли сохранённые копии).
* Если установленная игра подписана другим ключом или новее выбранной версии, Android не разрешит
  замену. Лаунчер объяснит причину; поддерживаемый путь — сохранить миры (экспорт из игры), удалить
  текущую версию в настройках системы и установить нужную.
* **Backup metadata** — экспорт сведений библиотеки (без APK) в JSON.
* Вкладка **Import history** — что было добавлено и что отклонено с причиной.

## Дополнения Bedrock
* **Bedrock add-ons → Import**: `.mcpack .mcaddon .mcworld .mctemplate .mcstructure .zip`.
  Проверяются manifest.json, UUID, версии, min_engine_version, зависимости, конфликты и дубликаты.
* **Open in Minecraft** — официальный способ: файл передаётся игре, она импортирует его сама.
* **Copy to com.mojang** — если ваша папка `games/com.mojang` доступна (например, игра хранит данные
  во внешнем хранилище), привяжите её кнопкой «Link com.mojang folder»; пакеты копируются в
  `behavior_packs`/`resource_packs`, миры — в `minecraftWorlds`. Доступ к `Android/data` чужих
  приложений на Android 11+ запрещён системой и не обходится.
* Фильтры по типу, категориям, поиск, включение/отключение, переименование, **Backup all**.

## Minecraft Java Edition
1. **Настройки → Microsoft accounts**: укажите Azure Client ID (приложение с включёнными public client
   flows и разрешением Minecraft API), нажмите **Add account**, откройте ссылку, введите код.
   Нужен аккаунт, владеющий игрой. Токены шифруются ключом из Android Keystore.
2. **Профили → New profile**: имя, описание, иконка, обложка, версия Minecraft (release/snapshot),
   загрузчик (Vanilla/Fabric/Quilt/Forge/NeoForge) и его версия, память (с предупреждением о безопасном
   пределе), пресет графики, JVM/игровые аргументы, разрешение. **Save & install** скачивает файлы
   (видно в уведомлении, можно отменить; загрузка продолжается в фоне и докачивается после обрыва).
3. Каждый профиль имеет свою папку: `mods`, `config`, `resourcepacks`, `shaderpacks`, `saves`.
4. **Версии** — список Mojang (release, snapshot, old beta/alpha), создание профиля из версии,
   проверка и удаление установленных версий.
5. **Java Edition** — статус файлов, **Install/Repair**, **Verify files**, **PLAY**, вкладки миров,
   датапаков и конфигов (встроенный редактор с резервной копией).
6. **PLAY** выполняет полную предстартовую проверку. В этой сборке нет нативного backend'а для
   исполнения Java Edition, поэтому запуск будет заблокирован с объяснением; можно посмотреть
   подготовленную команду запуска (токен скрыт).

## Моды, текстуры, шейдеры
* **Моды**: импорт `.jar`, включение/отключение (суффикс `.disabled`), удаление, поиск, сортировка,
  фильтры (включённые, отключённые, проблемные, библиотеки), подробности мода, резервная копия и
  восстановление. Проверка: формат загрузчика, версии Minecraft и загрузчика, обязательные/
  опциональные/несовместимые зависимости, дубликаты, отсутствие метаданных.
* **Resource packs**: проверка `pack.mcmeta` и соответствия `pack_format` версии игры.
* **Shaders**: проверка структуры и предупреждение, если нет Iris/Oculus/OptiFine.

## Сборки
* Импорт `.mrpack` (Modrinth: файлы скачиваются только с разрешённых спецификацией хостов и
  проверяются SHA-1) и `.eloapack` (экспорт этого лаунчера).
* Экспорт профиля в `.eloapack` (по желанию с мирами). Данные аккаунта не экспортируются.

## Файловый менеджер
Корни: данные Java, папки профилей, библиотека Bedrock, экспорт, резервные копии. Создание папок,
переименование, копирование/перемещение (через «Paste here»), удаление с подтверждением, импорт и
экспорт через системный выбор файлов, поиск, сортировка, размеры, проверка целостности
архивов + SHA-256, резервная копия папки в ZIP.

## Диагностика и журнал
* **Диагностика → Run**: место, каталоги, временные файлы, память, температура, сеть, библиотека
  Bedrock, дополнения, профили Java (целостность файлов, загрузчики, моды), runtime, аккаунты, ошибки
  и аварийные завершения. Для каждой проблемы — причина, серьёзность, компонент, решение; безопасные
  исправления выполняются сразу, рискованные — только после подтверждения.
* **Журнал ошибок**: фильтр по уровням, поиск, раскрытие stack trace, копирование, экспорт, очистка.
  Секреты (токены, пароли) маскируются до записи.
