# Eloa Launcher: как пользоваться

## Первый запуск
* Нижняя панель на телефоне: Главная, Библиотека, Моды, Миры, Аккаунты, Настройки. Остальные разделы — в Библиотеке и в меню ☰. На планшете все разделы на боковой панели.
* Лаунчер измеряет устройство и выбирает режим производительности. Проверить и сменить его можно в **Производительность**.
* Язык, тема, акцентный цвет, вариант главного экрана, плотность и размер элементов — в **Настройки → Оформление**.

## Главная
Две карточки. **Java Edition**: выбранный профиль, статус установки, режим запуска, Play, Settings (настройки игры профиля), Versions. **Bedrock Edition**: установленная версия Minecraft, Play (запускает официальное приложение), Settings и Versions (раздел Bedrock).

## Minecraft Bedrock Edition
* Блок «Minecraft на этом устройстве» показывает найденную версию и кнопку **Запустить Minecraft Bedrock**. Если игры нет — кнопка Google Play и пояснение.
* **Import APK**: свои файлы `.apk`, `.apks`, `.xapk`. Перед добавлением проверяются CRC архива, подпись и сертификат, пакет, версия, ABI, minSdk, дубликаты. Оригиналы только читаются.
* **Install** передаёт APK системному установщику, подтверждаете вы. Если установленная игра подписана другим ключом или новее, Android замену не разрешит; лаунчер это скажет до установки.
* **Дополнения Bedrock**: `.mcpack .mcaddon .mcworld .mctemplate .mcstructure .zip`. **Open in Minecraft** передаёт файл игре, она импортирует его сама. **Copy to com.mojang** работает, если вы выдали доступ к папке `games/com.mojang`.

## Миры
* **Bedrock**: выберите папку `games/com.mojang` (или `minecraftWorlds`), если игра хранит миры в общей памяти. Миры во внутренней памяти Minecraft Android не отдаёт: экспортируйте их из игры в `.mcworld` и нажмите **Import .mcworld**.
* У каждой копии: миниатюра, размер, дата, источник, версия, статус проверки. **Verify** читает весь архив и сравнивает SHA-256. **Restore** сначала проверяет копию, затем сохраняет мир с тем же именем папки и только потом заменяет его. Закройте Minecraft перед восстановлением.
* **Java**: миры выбранного профиля (импорт, экспорт, удаление с подтверждением).

## Java Edition
1. **Аккаунты**: укажите Azure Client ID (нужен ID, одобренный Mojang для Minecraft API; для входа через браузер добавьте redirect URI `eloa-launcher://auth`). Войдите через браузер или по коду. Пароль вводится только на странице Microsoft.
2. **Библиотека → Профили → Новый**: версия, загрузчик, память. Установка идёт в фоне; ход виден в **Загрузках** и в уведомлении. Пауза сохраняет скачанное, Resume докачивает.
3. **Настройки игры**: дальность прорисовки и симуляции, графика, VSync, FPS, масштаб рендера, частицы, облака, тени, освещение, HUD, FOV, звук, чувствительность, память, сборщик мусора, аргументы JVM, размер окна, среда Java. Сохранение записывает значения в `options.txt` профиля; остальные строки файла остаются.
4. **Среды Java**: импорт `.zip` со средой для Android/Linux под архитектуру устройства, проверка целостности, удаление. Java 8 нужна до 1.16.5, Java 17 для 1.17–1.20.4, Java 21 с 1.20.5.
5. **Режим запуска** (Аккаунты или карточка на Главной): Official account, Online (нужен интернет, для серверов), Offline (без сети, только для уже проверенного аккаунта; серверы с проверкой сессию не примут), Local singleplayer (Offline + сразу в выбранный мир, Minecraft 1.20+).
6. **Play** выполняет все проверки. В этой сборке нет бэкенда исполнения Java Edition, поэтому последней причиной будет «нет бэкенда»; подготовленную команду запуска можно посмотреть в окне результата.

## Скины
**Библиотека → Скины.**
* **Импорт PNG**: файл 64×64 или старый 64×32 (будет преобразован). Тип рук (классические или тонкие) определяется сам. Если выбрать обычную картинку, она откроется в режиме «Из фото».
* **Из фото**: выберите фото, двигайте рамку на лицо и меняйте её размер. Лицо переносится на переднюю грань головы, цвет волос — на макушку и бока. Остальное можно дорисовать в редакторе.
* **Нарисовать**: создаёт стандартный скин и открывает редактор.
* **Редактор**: выберите часть тела и грань, рисуйте пальцем. Инструменты: карандаш, ластик, заливка (не выходит за грань), пипетка; палитра и цвет в формате #RRGGBB; отмена и повтор. Второй слой (шапка, куртка, рукава, штанины) рисуется поверх основного, прозрачные пиксели показывают основной слой.
* **Действия** (нажмите на скин): изменить, переименовать, сохранить PNG, отправить в Bedrock (Minecraft откроет набор скинов), установить в профиль Microsoft (официальный сервис Minecraft, нужен аккаунт с Java Edition), удалить.

## Ely.by
1. Сначала добавьте аккаунт Microsoft с купленной Java Edition: без него вход в Ely.by недоступен.
2. **Аккаунты → Ely.by → Войти в Ely.by**: логин или e-mail и пароль. Если включена двухфакторная защита, появится поле для кода. Пароль отправляется только на authserver.ely.by и не сохраняется.
3. Сделайте аккаунт Ely.by активным. При запуске Java лаунчер скачает authlib-injector (проверяется SHA-256), и скин будет виден на серверах Ely.by. Официальные серверы Mojang такой аккаунт не принимают.
4. Скин для Ely.by загружается на сайте ely.by (кнопка «Открыть ely.by» на экране скинов).

## Производительность
* Режимы: Battery Saver (30 FPS, меньше дальность и масштаб), Balanced (60 FPS), Performance (без VSync, проще графика), Extreme Performance (дальность 4, минимум частиц, масштаб 60%), Custom. Режим применяется к выбранному профилю.
* Память: всего, занято, свободно, сам лаунчер, куча Java профиля с безопасным пределом.
* Рендереры: для GPU и версии Minecraft показано, какие слои совместимы и почему остальные нет.
* Температура: статус Android, тепловой запас, батарея. При перегреве — уведомление и кнопка Battery Saver.

## Управление
* **Сенсорные раскладки**: создайте раскладку из пресета (Classic, Compact, PVP, Survival, Controller-like, Custom), перетаскивайте элементы, меняйте размер, ширину, прозрачность, подпись и действие. Импорт и экспорт в JSON.
* **Геймпады и клавиатуры**: список подключённых устройств, тест кнопок и стиков, раскладка для каждого контроллера, мёртвая зона, чувствительность, инверсия Y.

## Уведомления, журнал, обновления
* Колокольчик в верхней панели: завершённые загрузки, ошибки установки, нехватка места, повреждённые файлы, перегрев, обновления.
* **Краши и журнал**: анализ известных причин сбоев с подсказкой; кнопка анализа журнала игры (`logs/latest.log`) или отчёта о сбое. Экспорт и очистка журнала.
* **Обновления**: проверка GitHub Releases. Устанавливается только APK с опубликованным SHA-256 и той же подписью. Ежедневная проверка выключена по умолчанию.
* **Конфиденциальность**: что хранится и куда лаунчер обращается; удаление всех данных.
